## Project Overview

EcommerceApp is a Java J2EE Online Electronic Shopping application. It is built using raw Servlet 3.0 + JSP with a SQLite database accessed via plain JDBC through five DAO classes. There is no Spring, no ORM, and no DI container. The application is packaged as a WAR and deployed on Apache Tomcat 8+.
